# Codex Rewind

为 Windows 本地 Codex 回答的 `···` 菜单增加 **回退到本轮之前**，放在“分支到新聊天”正下方。

点击后，读取选中轮次及后续记录，发送预设 Prompt 让 AI 撤销可恢复的操作；只有 AI 报告全部完成、未解决项为空且会话未出现其他新轮次时，才截断目标轮及后续会话，包括回滚请求本身。

**这是实验性的非官方补丁。仓库仅提供补丁代码和工具，不分发 Codex 安装包、修改版二进制、账号数据或聊天记录。**

## 兼容范围

- 已适配 Windows 包版本 `26.1016.8120.0`，应用内部版本 `26.1016.61520`。
- 支持本地 `local` 主机、已加载的 `paginated` 历史格式的 Codex 会话。
- 普通 ChatGPT 聊天、云端 Work、远程主机及旧格式会话尚未接入。
- 构建脚本检查原包的资源头指纹及补丁锚点；不匹配时拒绝修改。不要强行套用到其他版本。

## 本地构建

需要 Python 3.10+、Node.js 20+，以及自行安装的兼容版 Codex。构建仅使用标准库，不需要安装第三方 Python 或 npm 包。

```powershell
git clone <本仓库的 GitHub 地址>
cd codex-rewind
python scripts/build.py --source "C:\path\to\Codex\app"
```

`--source` 指向包含 `ChatGPT.exe` 和 `resources/app.asar` 的应用目录。构建过程读取原安装，生成 `dist/Codex-Rewind/` 独立副本；不会修改原版、接管目录权限或关闭原版进程。需要约 3 GB 可用空间。已有输出目录不会被覆盖。

完全退出原版 Codex（含托盘）后，双击 `dist/Codex-Rewind/launch-rewind.cmd`。进入本地 Codex 聊天，在一条已完成的回答下方打开 `···`，选择 **回退到本轮之前**。

独立副本保留资源完整性检查，并将校验值更新为修改后的资源。修改的可执行文件不再具有原版有效签名，不是官方发行版，也没有自动更新机制。

## 行为与限制

- 先把恢复记录保存到本机 IndexedDB，再提交回滚 Prompt。
- 0.1.1 起，导出恢复记录使用原生“另存为”窗口。成功后显示保存路径；取消或失败均明确提示，记录仍保留在本机。
- Prompt 要求覆盖文件前在工作区 `.codex-rewind-backups/` 中保存当前内容，按操作归属撤销，保留用户或其他任务独立产生的修改。
- 回滚沿用当前会话权限；不绕过授权，不自动批准提权。
- 出现部分失败、缺失备份、无法判断归属、报告格式错误或并发新消息时保留会话记录。已撤销的操作不会自动重做。
- 回滚运行中，请勿向同一聊天发送其他消息或同时修改相同文件。Prompt 和执行过程在成功截断前可能可见。
- 跨聊天记忆和全局说明保持原样。单纯隐藏消息不是本版的降级方案。
- **AI 报告完成不等于独立验证所有操作。**本版不是系统快照，无法保证撤销任意数据库变更、安装行为或外部服务操作。请先在有备份的测试项目中使用。
- 恢复记录可从结果面板导出，可能包含聊天和工具输出；不要将其上传到公开仓库。导出记录尚无一键恢复会话的导入功能。
- 关闭修改版可重新打开原版，但已成功截断的聊天历史不会因为换回原版而自动恢复。

## 验证

```powershell
npm test
python -m unittest discover -s tests -p "test_*.py" -v
```

使用本机正版资源执行实际菜单组件测试（资源不会提交到 Git）：

```powershell
python scripts/build.py --source "C:\path\to\Codex\app" --prepare-only
npm run test:menu
```

可选的真实模型测试会消耗 Codex 配额、创建测试会话并修改 `.work/live-test/` 内的测试文件。它不自动批准权限请求；应在测试环境运行：

```powershell
node tests/live-rewind.cjs "C:\path\to\codex.exe"
```

当前成果已验证独立副本启动、菜单结构、失败保护、真实文件恢复、后端截断及重新加载。原型已由使用者反馈在界面中测试成功；自动化端到端测试通过后端执行，未冒充原生鼠标点击测试。

CI 配置示例保存在 `docs/ci-example.yml`，尚未自动启用 GitHub Actions。`npm test` 和 Python 测试可直接在本地运行。

## 代码

- `src/rewind-controller.js`：回滚 Prompt、恢复记录、状态面板和会话截断。
- `scripts/patchlib.py`：该版本的精确菜单与会话管理器补丁、ASAR 重建。
- `scripts/build.py`：读取本地正版资源，生成独立修改版。
- `tests/`：控制器、菜单结构、资源重建及可选真实模型测试。
