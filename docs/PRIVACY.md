# 隐私说明

公开仓库只包含补丁源码、构建脚本、合成测试、说明文档及 CI 配置。

不包含开发者电脑上的用户名或目录、个人邮箱、聊天原文、账号配置、登录凭证、访问令牌、运行日志、浏览器资料、真实回退恢复记录或任何 Codex 二进制。测试中的路径和消息是通用示例或运行时生成的数据。

提交作者使用项目名称和项目用的 noreply 地址，不使用本机 Git 全局配置中的姓名或邮箱。GitHub 仓库所属账号及平台公开元数据仍由 GitHub 展示。

补丁运行时会将选定的历史内容作为回滚 Prompt 发给当前 Codex 模型，并把恢复记录保存到本机 IndexedDB；它不额外引入第三方遥测或上传端点。原版 Codex 本身的数据处理规则不受本补丁改变。

恢复记录、真实测试结果和文件恢复副本可能包含敏感信息，默认通过 `.gitignore` 排除。请勿强制添加这些目录，也不要将完整日志附加到公开 issue。

发布前应检查全部待提交文件和 Git 作者元数据，而不只依赖 `.gitignore`。
